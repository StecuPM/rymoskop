# Rymoskop

> Wklej polski tekst piosenki albo wiersza i zobacz, jak brzmi i jak się rymuje: transkrypcja fonetyczna (IPA), sylaby, akcenty, rodziny rymów i statystyki. Wszystko działa w przeglądarce.

Paste Polish lyrics or a poem and see how they sound and how they rhyme. Everything runs in the browser: no backend, no API keys, no AI calls at runtime.

**Status:** work in progress. See [`docs/SPEC.md`](docs/SPEC.md) for the product and [`docs/PHASES.md`](docs/PHASES.md) for the build plan.

## Run locally

```bash
npm install
npm run dev
```

## Sample texts and artistic freedom

The sample and evaluation texts in this repository (`eval/`) are either public-domain Polish poetry or verses written by the repository owner. They are used only as test material for phonetic and rhyme analysis. Lyrics and poetry rely on artistic freedom, so these texts may use language, themes or phrases that do not meet everyone's standards. They are not meant to offend anyone, and their content does not express the views of the author of this project.

**Zastrzeżenie:** teksty przykładowe i testowe w tym repozytorium to poezja z domeny publicznej albo zwrotki napisane przez autora projektu. Służą wyłącznie jako materiał do analizy fonetycznej i rymów. Teksty piosenek i poezja korzystają z wolności artystycznej, więc mogą zawierać język, motywy lub sformułowania niezgodne z niektórymi normami. Nie mają na celu nikogo urazić i nie wyrażają poglądów autora projektu.
